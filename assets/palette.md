# HALO / LIFE.OS Color Palette

LIFE.OS のカラートークンの正本。ヒーロー画像（`halo.svg`）やバッジの色はここに合わせる。

| Token | Hex | Use |
|---|---:|---|
| Background | `#080A12` | Main background |
| Surface | `#111522` | Cards / panels |
| Cyan | `#00E5FF` | Primary accent |
| Purple | `#8B5CF6` | Secondary accent |
| Pink | `#FF4FD8` | Highlight |
| Text | `#F4F7FF` | Main text |
| Muted | `#6F7A90` | Secondary text |

## Rule

Neon colors should be used sparingly for:
- headings
- separators
- badges
- borders
- small status elements
