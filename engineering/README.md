## Format

各プロジェクトは `projects/<project-name>.md` に以下の形式で残します。

```md
# Title

## Problem
## Idea
## Architecture
## Implementation
## Result
## Lessons Learned
```

## Certifications / Outputs

資格・技術記事・登壇を追加する場合は、[profile.md](./profile.md) に `## // CERTIFICATIONS` / `## // OUTPUTS` セクションを作り、実在するものだけを載せる（空のセクションは置かない）。

```md
## // CERTIFICATIONS

| Name | Year |
|---|---|
| 資格名 | YYYY |

## // OUTPUTS

- [記事タイトル](URL) — 媒体 / YYYY-MM
```
