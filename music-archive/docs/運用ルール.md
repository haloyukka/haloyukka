# 運用ルール

## 保存単位

- `songs/アーティスト名/曲名-年.md` に原曲1曲につき1ファイルを保存する。年は最初に登録したお気に入り動画の公開年。
- 同じ曲の原曲・カバー・ライブ映像はその1ファイルにまとめる。カバーは原曲アーティストのフォルダに置く。
- 複数のアーティストが共同で制作した曲は `songs/コラボ/` に置き、`contributors` に参加者を記載する。
- 同じフォルダでファイル名が重なる場合は、末尾に区別できる短い語を追加する。既存ファイルを上書きしない。
- 動画の公開年が不明な間は確認してからファイルを作る。後でお気に入り動画が変わってもファイル名は維持する。

## 一覧の手動更新

- 曲を追加したら、アーティストの `README.md` の表に追記する。
- 初めてのアーティストなら、アーティスト別フォルダとその `README.md` を作り、トップの `README.md` にも1行追加する。
- コラボ曲は `songs/コラボ/README.md` の表に追記する。
- 一覧のジャンル・雰囲気・カラオケ状態は、曲ファイルの内容と一致させる。
- 動画リンクは曲ファイルを正とし、一覧には代表動画へのリンクだけを任意で載せる。

## 値の目安

- `genre` は一つの主なジャンルを記入する。例：ボカロ、ロック、ポップス。
- `moods` は複数可。例：疾走感、ダーク、爽やか、しっとり。表記を揃えるとGitHub検索がしやすい。
- 空欄や「未確認」は許容する。確認していないYouTube URLや公開年を推測で記入しない。

## セトリ

- `setlists/_template.md` をコピーして作成する。
- 曲への相対リンクを貼り、曲の詳細と動画URLは曲ファイルで管理する。
- 曲ファイルの名前や場所を変えた場合は、アーティスト一覧とセトリのリンクも直す。
